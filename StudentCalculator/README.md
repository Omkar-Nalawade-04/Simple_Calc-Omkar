## Requirements
- Java JDK installed
- Windows, Linux, or macOS with a desktop environment

## How to Run
Open a terminal in this folder and run:

```bash
javac Calculator.java
java Calculator
```

## Features
- Addition, subtraction, multiplication, and division
- Percentage, decimal, and plus/minus
- Clear and delete
- Division-by-zero error handling
- Student details displayed at the top

The project uses only Java's built-in Swing and AWT libraries.
